verified ground truth"*) can miss a **transposition**, because it inspects only the line the
deletion sits on. All 33 removals below were certified by that same procedure. Each needs a
look at the facsimile image before it is trusted.

Longest readings first: a moved phrase is what the check misses, and a single dropped
function word is far less likely to be a transposition.
